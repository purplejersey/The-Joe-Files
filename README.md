# Joe: One Last Plant Lap

The main game is now a workplace adventure through four fictionalized JEP departments: Receiving, Assembly, Break Room, and the Boss's Office. Joe has a photo-based transparent head sprite made from the supplied reference, animated on his cartoon body. Nine linked objectives combine exploration, coworker dialogue, an inventory trade, a medical detour, dating messages, and a timed “erratic” word challenge. There is no countdown. Maximum worry triggers a coffee break and keeps quest progress. Arrow keys/WASD/thumbstick move; E/Space/GO interact. P pauses. Original stories remain in Joe Files. This is fictional comedy, not a map or representation of actual plant operations.

Run `node adventure-check.cjs` for progression and control checks. These use a mocked canvas/DOM and do not replace a visual browser playthrough. Browser automation could not inspect the local file URL under its security policy.
